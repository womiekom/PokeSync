## 4. Gen 9 Data Gap

### The Problem

PokeSync's Pokémon database (`pokemon_complete.csv`) includes Gen IX Pokémon with full mechanical data (stats, types, abilities). However:

1. **No move/learnset data exists** in the repository for ANY generation, let alone Gen IX.
2. **No competitive usage data exists** in the repository for ANY generation.
3. **External competitive datasets** that were investigated appear to primarily cover Gen 8 or earlier (this is common since Gen 9 competitive data was less available when many Kaggle datasets were published).

### What This Means for Phase 3

| Scenario | Gen I–VIII | Gen IX |
|----------|-----------|--------|
| Team synergy analysis | ✅ Works | ✅ Works |
| Archetype prediction | ✅ Works | ✅ Works |
| Moveset recommendation (deterministic) | ⚠ Needs move/learnset data | ⚠ Needs move/learnset data |
| Moveset recommendation (ML-enhanced) | ⚠ Needs competitive data | ❌ Competitive data likely unavailable |
| Team optimization | ⚠ Partially possible | ⚠ Partially possible |

### Potential Sources to Investigate

> **⚠ None of these have been integrated yet. This is a research list only.**

| Source | Type | Gen IX Support | Access Method | Notes |
|--------|------|---------------|---------------|-------|
| **PokéAPI** | REST API | ✅ Yes (v2) | HTTP GET requests | Comprehensive move/learnset data for all gens. Rate-limited. Could bulk-download for offline use. |
| **Pokémon Showdown** | Usage logs + sets | ✅ Yes | Public stats pages, GitHub repos | Monthly usage statistics by format/tier. Best source for competitive meta data. |
| **Smogon Usage Statistics** | Aggregated stats | ✅ Yes | `smogon.com/stats/` | Monthly CSV/text files of usage, moveset, teammate data by format. |
| **Smogon Strategy Dex** | Expert-curated sets | ✅ Yes (partial) | Web scraping or API | Recommended sets, EV spreads, items per Pokémon. |
| **PokéAPI GitHub Bulk Data** | Static data | ✅ Yes | Git clone | Pre-built CSV/JSON files of all Pokémon data including moves and learnsets. |
| **Veekun Pokédex** | SQLite database | ⚠ Varies | Download | Comprehensive mechanical data, may lag on Gen IX. |

### Recommended Investigation Priority

1. **PokéAPI** — for move database and learnsets (broadest coverage, official)
2. **Smogon Usage Statistics** — for competitive moveset frequency data
3. **Pokémon Showdown data** — for team composition patterns
4. **Kaggle competitive datasets** — re-evaluate the three previously investigated datasets

## 6. Data Quality & Risks

### Known Risks

| Risk | Severity | Description | Mitigation |
|------|----------|-------------|------------|
| **Gen 8 vs Gen 9 mismatch** | 🟡 Medium | Competitive usage datasets typically cover Gen 8; PokeSync's Pokémon data covers Gen IX. Recommendations for Gen IX Pokémon may lack competitive backing. | Clearly label when competitive data is unavailable; fall back to deterministic-only recommendations. |
| **Temporal meta drift** | 🟡 Medium | Competitive meta changes between game patches, DLC releases, and tournament seasons. Static datasets become stale. | Use date-stamped data; consider periodic refresh mechanism; document data freshness. |
| **Missing battle logs** | 🟢 Low | No win/loss data means we can't directly train on "what wins games". | Use usage frequency as proxy for competitive viability. |
| **Aggregated usage data** | 🟡 Medium | Smogon usage stats are aggregated across all skill levels, not just top players. | Filter by high-rating games if available (1825+ in Smogon stats). |
| **Possible target leakage** | 🟡 Medium | If competitive usage data includes moveset data alongside performance data, naive training could leak. | Carefully separate features from targets; use cross-validation. |
| **Format mismatch** | 🟡 Medium | Singles, Doubles, VGC have drastically different competitive dynamics. A moveset good in Singles may be bad in VGC. | Either support multiple formats explicitly or document which format recommendations target. |
| **Illegal move recommendations** | 🔴 High | If learnset data is incomplete or outdated, the system may recommend moves a Pokémon cannot learn. | **Always enforce learnset filtering as a hard constraint before any ranking.** |
| **Dataset licensing uncertainty** | 🟡 Medium | Kaggle datasets and Smogon data have varying licenses. Some may restrict commercial use. | Review licenses before integration; prefer openly-licensed or self-collected data. |
| **Synthetic training data limitations** | 🟡 Medium | The current archetype model is trained on synthetically generated teams, not real competitive teams. Extending this approach to Phase 3 may produce unrealistic recommendations. | Consider supplementing with real competitive data if available. |
| **Ability interaction complexity** | 🟢 Low | The current `strategies.py` only covers a subset of competitive abilities. Many ability-move interactions exist (e.g., Protean, Libero, Technician). | Expand strategy definitions incrementally. |
| **Move interaction complexity** | 🟡 Medium | Some moves interact in ways that simple scoring can't capture (e.g., Stealth Rock + Rapid Spin, Wish + Protect, Volt Switch + U-turn). | Consider move synergy patterns as an advanced Phase 3 enhancement. |
| **Form differences** | 🟢 Low | Pokémon forms (e.g., Rotom-Wash vs Rotom-Heat) have different types and may have different learnsets. The dataset includes forms but learnset differences need careful handling. | Treat each form as a distinct entity for learnset purposes. |
